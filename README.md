# KinoDeutsch Презентация - Инструкция по использованию

## 🎯 Как использовать презентацию

### Вариант 1: Онлайн-демонстрация
- Откройте ссылку на презентацию в браузере
- Нажмите F11 для полноэкранного режима
- Используйте стрелки клавиатуры для навигации
- Все анимации работают автоматически

### Вариант 2: Локальные файлы
1. Распакуйте ZIP-архив
2. Откройте любой .html файл в браузере
3. Для презентации по порядку:
   - title_slide.html (Титульный слайд)
   - vision_mission.html (Vision & Mission)
   - founders_team.html (Команда основателей)
   - product_overview.html (Обзор продукта)
   - key_features.html (Ключевые функции)
   - market_opportunity.html (Рыночные возможности)
   - business_model.html (Бизнес-модель)
   - competitive_advantage.html (Конкурентные преимущества)
   - financial_projections.html (Финансовые прогнозы)
   - call_to_action.html (Призыв к действию)

## 🎨 Особенности дизайна
- Кинематографический стиль в черно-красной гамме
- Анимированные элементы и переходы
- Адаптивный дизайн для разных экранов
- Профессиональная типографика

## 💡 Советы для презентации
- Используйте полноэкранный режим (F11)
- Дайте время для загрузки анимаций
- Подготовьте заметки для каждого слайда
- Тестируйте на том же устройстве, где будете презентовать

## 🔧 Техническая информация
- Все файлы работают в современных браузерах
- Не требуется интернет для локальных файлов
- Размер презентации: ~1280x720px (16:9)
- Используются веб-технологии: HTML5, CSS3, JavaScript

Удачи с презентацией! 🚀
