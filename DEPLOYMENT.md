# KinoDeutsch Презентация - Инструкция по размещению на сервере

## 🌐 Размещение на kinodeutsch.de

### Файлы для загрузки:
- `index.html` - Главная страница с навигацией
- `navigation.js` - Скрипт навигации между слайдами
- Все 10 HTML файлов слайдов
- `README.md` - Эта инструкция

### Структура на сервере:

## 🚀 Как использовать:

### Для презентации:
1. **Главная страница**: `https://kinodeutsch.de/`
2. **Прямой старт**: `https://kinodeutsch.de/title_slide.html`
3. **Конкретный слайд**: `https://kinodeutsch.de/vision_mission.html`

### Навигация:
- **Стрелки клавиатуры**: ← → ↑ ↓ для перехода между слайдами
- **Пробел**: Следующий слайд
- **Home**: Первый слайд
- **End**: Последний слайд
- **Escape**: Возврат на главную
- **Кнопки на экране**: Стрелки слева/справа
- **Меню**: Кнопка "Menu" в правом верхнем углу

### Счетчик слайдов:
Внизу экрана показывается: "3 / 10 - Gründerteam"
