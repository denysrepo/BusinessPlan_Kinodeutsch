## Инструкции по загрузке:

1. **Скачайте архив** `kinodeutsch_website_fixed.zip`
2. **Распакуйте** все файлы
3. **Загрузите** содержимое в папку `public_html` на сервере
4. **Проверьте** что папка `images/` загружена корректно
5. **Откройте** https://kinodeutsch.de/ для проверки

## Навигация:

- **Стрелки клавиатуры**: ← → для перехода между слайдами
- **Кнопки на экране**: Стрелки слева/справа
- **Меню**: Выпадающее меню со всеми слайдами
- **Прямые ссылки**: kinodeutsch.de/title_slide.html и т.д.
